// capabilities

Everything a university
backend needs

Built with real production patterns — caching, async tasks, role-based access, and live sandboxed code execution.

🎓
Academic Management

Full CRUD for students, faculty, courses, departments, and semester lifecycle with role-based permissions per module.

⚡
Live Code Execution

Isolated compiler microservices for Python, C/C++, and Java. Each runs in its own container, sandboxed per request with timeout protection.

🔐
JWT Authentication

Secure token-based auth with access and refresh tokens, configurable lifetimes, and role-aware permission classes.

🚀
Two-Layer Redis Cache

Class-level cache pre-built by Celery on semester activation. Student-level cache built on demand. Dramatically reduces DB load.

📋
Async Task Queue

Celery workers handle cache warming, email notifications, and GPA recalculation asynchronously with Redis as the broker.

☁️
Cloud Storage + CI/CD

Cloudinary for media. GitHub Actions auto-deploys every push to Azure VM. Zero-downtime rebuilds with Docker Compose.
